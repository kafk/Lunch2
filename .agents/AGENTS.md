# Project Rules

- **Version Management**: Always update the `VERSION` variable in [app.py](file:///c:/Users/darko/OneDrive/företaget/Lunch2/app.py) whenever changes are committed and pushed to GitHub.
  - The version format is `3.<number>` (e.g. `3.31`).
  - The decimal part increments on each push (e.g. `3.31` -> `3.32`) and goes up to `99` before rolling over to `4` (or `4.0`).
